Agents in production

Systems I designed and shipped at TerraPay. The code is company-owned, so these are write-ups rather than repos; I'm happy to walk through the architecture in detail.

Enterprise knowledge assistant

RAG system · TerraPay

One assistant that answers questions across onboarding, due-diligence, legal, compliance and sales documents, and only shows each person what they're cleared to see.

Retrieval
Hybrid search on pgvector with cross-encoder re-ranking, orchestrated in LangChain and LangGraph.
Access control
ACL and JWT pre-filtering before retrieval, so restricted documents never reach the model.
Operations
Content hashing to skip re-indexing unchanged files; Guardrails AI on inputs and outputs; Langfuse for prompt versioning and tracing; DeepEval for evaluation.
8departments using it
60%+faster average query resolution

TxQuery AI

Multi-agent support · TerraPay

A team of AI agents that resolves customer-support tickets about cross-border transactions, from inbox to reply.

Intake
Unifies Outlook queries into Freshdesk tickets; classification agents label each by intent (status, cancellation, reversal, failure).
Resolution
Extracts transaction IDs, runs database and API lookups, and routes to specialised LangGraph nodes with tool calling and memory.
Integration
Freshdesk through an MCP server, SSE streaming, Chainlit front end.
60%of tickets automated
4h → 15maverage response time
